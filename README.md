# series-homework

פונקציות JavaScript לאתר הסדרות SeriesHub: קריאת נתונים מ־JSON, פונקציות של מערכים ועדכונים בלי לשנות את המקור.

## הרצת הבדיקה

```
node check.js
```

## שאלות

**1. למה ב־`addEpisode` לא מספיק `{ ...show }`?**

`{ ...show }` מעתיק רק את השכבה העליונה, ולכן המערך `seasons` והעונות שבתוכו נשארים אותם אובייקטים כמו במקור. יצרתי מחדש את מערך הסדרות (עם `map`), את הסדרה שמשתנה, את המערך `seasons`, את העונה שמשתנה ואת המערך `episodes` שלה (עם `[...season.episodes, episode]`). את שאר הסדרות והעונות השארתי כמו שהן, כי לא נגעתי בהן.

**2. למה העותק בתקלה #3 לא עזר?**

העמית עשה `push` לתוך `firstSeason.episodes` לפני שעשה את העותק, ו־`firstSeason` הוא הפניה לאותה עונה שנמצאת בסדרה המקורית. כך המקור כבר השתנה. וגם אם העותק היה נעשה קודם, `{ ...show }` הוא עותק רדוד, אז `seasons` עדיין מצביע לאותו מערך כמו במקור.
